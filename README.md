# Control Plagas 3D Aranjuez — Propuesta de rediseño web

Prototipo de homepage para **Control Plagas 3D Aranjuez**, empresa de control de plagas con más de 25 años en Aranjuez y el sur de Madrid.

**Dirección estética:** *"Lámina"* — la plancha del naturalista. Las plagas se dibujan, no se fotografían: nadie quiere ver una cucaracha en primer plano, y un espécimen trazado a línea transmite conocimiento en vez de asco.

## Stack
HTML, CSS y JavaScript puro. Cero dependencias, cero build. Fuentes variables autoalojadas y láminas en SVG en línea.

## Objetivos técnicos
LCP < 1,5 s · CLS < 0,05 · INP < 200 ms · Lighthouse 95+ en las cuatro categorías.

## Ver en local
```bash
cd prototype && python3 -m http.server 8000
```
